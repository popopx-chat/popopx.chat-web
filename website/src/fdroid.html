POPOPX is not on F-Droid

No F-Droid repository, no APK from us

POPOPX Chat is not available on F-Droid.

We publish no F-Droid repository of our own and we publish no Android APK. There is no repository URL and no signing fingerprint for POPOPX to add, so any F-Droid entry, repository address or APK that claims to be POPOPX is not ours.

The F-Droid repository at app.simplex.chat belongs to SimpleX Chat

The address app.simplex.chat/fdroid/repo is the F-Droid repository of SimpleX Chat, the upstream project POPOPX is derived from. That repository, its APK builds and its signing key are operated by SimpleX Chat, not by POPOPX.

Adding it to F-Droid installs SimpleX Chat. It will not install POPOPX Chat, and the two apps are separate applications that are not interchangeable.

How to get POPOPX

Install POPOPX Chat from the downloads page — it lists only the builds we actually publish and support.

If POPOPX is missing from the platform you use, tell us; we would rather say so than point you at a build we do not control.

More about F-Droid itself, the free and open source Android app store, at f-droid.org.
