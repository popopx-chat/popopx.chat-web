# SimpleX Directory

Welcome to the selected users' communities that you can join via [POPOPX Chat app](https://popopx.chat/downloads).

SimpleX Directory is also available as a [SimpleX chat bot](https://smp4.simplex.im/a#lXUjJW5vHYQzoLYgmi8GbxkGP41_kjefFvBrdwg-0Ok).

The directory service, its listing and its bot are operated by [SimpleX Chat](https://simplex.chat/), the upstream project POPOPX is derived from. POPOPX does not run the directory, does not store this data and does not moderate the entries; the list below is loaded from directory.simplex.chat.

Read about [how to add](https://simplex.chat/docs/directory.html) your community (SimpleX Chat docs).

All listed groups and channels in JSON, with names, descriptions, member counts, join links and activity times: [directory.simplex.chat/data/listing.json](https://directory.simplex.chat/data/listing.json).
