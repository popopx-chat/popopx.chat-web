# Upstream documents

Except for the three pages listed at the end of this one, every document in this corpus was written for
[SimpleX Chat](https://simplex.chat) by SimpleX Chat Ltd, the company whose project POPOPX Chat forks. POPOPX
reproduces their text so that the protocol design, the server guides and the audit history can be read next to
our build. What those documents are not:

1. **They are not POPOPX policy.** They state SimpleX Chat Ltd's design decisions and their services. Where one
   of them conflicts with what POPOPX says about itself - see [Privacy](/privacy/) - POPOPX's own pages govern.
2. **They are not POPOPX contacts.** An email address, an OpenPGP key, a store link, a supporter badge, a
   support channel or a relay host named inside one of these documents belongs to the party that wrote it; that
   a POPOPX build reaches a service SimpleX Chat Ltd operates is the fork's expected behaviour, not an
   endorsement of the service or of the text describing it. POPOPX's own contact is
   [chat@popopx.chat](mailto:chat@popopx.chat), and no page in this corpus is a POPOPX security policy.
3. **They are not maintained here.** Upstream's repository and site hold the current, authoritative text. A page
   on this host is a snapshot taken from it, so where the two differ the difference is POPOPX's change - read it
   as ours, never as upstream's statement - and a link inside a snapshot that resolves only on simplex.chat
   stays upstream's address.

The three pages POPOPX writes for this corpus are this disclaimer, the [/docs/ index](/docs/) and the
[POPOPX trademark policy](/docs/TRADEMARK-POPOPX.md). They carry no notice above their contents, because that
notice describes the other pages.
