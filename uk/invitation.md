## Встановлення POPOPX Chat для терміналу

Використовуйте цю команду:

curl -o- https://raw.githubusercontent.com/simplex-chat/simplex-chat/master/install.sh | bash

Дивіться POPOPX Chat Репозиторій GitHub для інструкції з того, як його завантажити чи скомпілювати з вихідного коду.
